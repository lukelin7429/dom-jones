用 Gemini 寫網頁

不寫程式碼，也能做出自己的教學網站。
三個步驟：產生首頁、擴充內頁、後續維修。

  • 先建立觀念

  • 2. 擴充成完整網站

先建立三個觀念

① 一個網站，其實就是一堆 .html 檔案

你看到的每一個網頁，背後都是一個檔案。一個學校網站的資料夾，可能長這樣：

my-website/ ├── index.html ← 首頁（封面） ├── lesson1.html ← 第一單元 ├── lesson2.html ← 第二單元 └── images/ └── school.jpg ← 圖片資料夾

瀏覽者打開網站，預設先看到的就是 index.html。其他頁面用「連結」串起來。

② Gemini 的 Canvas 是這次研習的主角

Gemini（gemini.google.com）有一個「Canvas」模式，可以邊寫 HTML 邊預覽，就像在 Word 寫文件一樣即時看到結果。我們今天不用對話框，全程都在 Canvas 裡操作。

怎麼開啟 Canvas 在 Gemini 對話框下方，找到「Canvas」按鈕點下去；或在訊息開頭打「請使用 Canvas」，它會自動切過去。

③ 你是設計師，Gemini 是工讀生

Gemini 不會猜你心裡的想法。你給的指令越具體（顏色、結構、字體、要幾個區塊），它就越接近你要的。今天我們會練「怎麼描述需求」這件事。

1. 怎麼產生 index 首頁

index 是整個網站的封面。先把首頁做出來，後面才有方向。

  1. 打開 Gemini，切到 Canvas 模式 網址：gemini.google.com → 在對話框點「Canvas」。
  2. 用下方的範本，把【】裡換成你的內容 不要光說「幫我做網站」，要說「我要做什麼樣的網站」。
  3. 送出後，等 Canvas 右側即時生成預覽 左邊是程式碼，右邊是實際看到的樣子。
  4. 看不順眼，繼續用中文跟它說「把標題改大一點」「換成深綠色」 它會直接更新 Canvas，不需要重新貼 code。
  5. 滿意後，按 Canvas 右上「下載」或「複製程式碼」 存成 index.html。完成。

可直接複製的 Prompt

請使用 Canvas，幫我寫一個 index.html（單檔，含 HTML + CSS）。 【主題】OO 國小三年級英語課首頁 【需要的區塊】 1. 大標題：學校名稱 + 一句英文 slogan 2. 簡短歡迎詞（兩句話） 3. 三張卡片，分別連到三個單元： - Unit 1 - My Family（連到 lesson1.html） - Unit 2 - My School（連到 lesson2.html） - Unit 3 - My Hobbies（連到 lesson3.html） 4. 頁尾：老師署名與學校名稱 【設計要求】 - 白底，主色用溫暖的橘色 (#F58220) - 中文字體請用 'PingFang TC' - 字級要大，方便小學生閱讀 - 手機上也要看得清楚（要 responsive） 請輸出完整單檔 HTML，CSS 直接寫在 <style> 標籤裡。
為什麼這樣寫 指定主題、區塊、設計風格、技術細節（單檔、responsive），四件事都講清楚，Gemini 第一次就能交出可用的版本。

2. 如何擴充成完整網站

首頁做完，接下來把連結的每個內頁也做出來。原則：一次只做一頁，不要叫它一次寫整個網站。

  1. 在同一個 Canvas 對話裡，接著請它寫第二頁 Gemini 會記得首頁的設計風格，新頁面會自動延續配色與字體。
  2. 每寫好一頁，就下載存成對應的檔名 lesson1.html、lesson2.html…檔名要跟首頁裡的連結對得起來。
  3. 圖片用佔位符，自己後製換上 Gemini 不會生圖片，要的圖你自己拍或找。命名清楚放進 images/ 資料夾。
  4. 每寫完一頁，先在自己電腦上雙擊 .html 開來看 瀏覽器會直接打開檔案，可以確認連結通不通、樣子對不對。

可直接複製的 Prompt（內頁）

請延續剛剛 index.html 的設計風格與配色， 幫我寫 lesson1.html（單檔 HTML + CSS）。 【主題】Unit 1 - My Family 【需要的區塊】 1. 頁面最上方：一個返回首頁的連結 → 寫成 <a href="index.html">← 回首頁</a> 2. 單元簡介（兩句中英對照） 3. 五張單字卡片，並排顯示，每張內含： - 英文單字（大字） - 中文翻譯 - 一個 emoji 單字：father 👨 / mother 👩 / brother 👦 / sister 👧 / pet 🐶 4. 例句區塊：「This is my family.」（大字置中） 5. 頁尾與 index.html 一致 請輸出完整單檔 HTML。
給研習老師的提醒 教學網站的內頁通常都長得很像（單元簡介＋單字卡＋例句＋返回連結）。第一頁做好以後，後面的頁面可以用「同樣結構，主題換成 OO」這種短指令快速複製。

3. 後續網頁要修改時的維修流程

這是大部分老師會卡關的地方。一定要記住一句口訣：

維修黃金口訣 「只改 X，其他完全不要動，輸出完整版」

標準維修五步驟

  1. 先備份 把要改的檔案（例如 lesson1.html）複製一份，改名 lesson1_backup.html。改壞了還有救。
  2. 用記事本／TextEdit 打開原檔，全選複製 Mac：Cmd+A 全選 → Cmd+C 複製。Windows：Ctrl+A → Ctrl+C。
  3. 到 Gemini Canvas，先貼上原始碼，再下指令 順序很重要：先讓它看到完整現況，再告訴它要改什麼。
  4. 下指令要「精準＋限制範圍」 指明改哪裡、不要動哪裡，要求輸出完整版（不是只回給你改的那段）。
  5. 拿到新版 → 覆蓋原檔 → 瀏覽器打開檢查 確認沒問題才上傳到 GitHub。

可直接複製的 Prompt（修改既有頁面）

以下是我目前的 lesson1.html。 請你只做一件事：把「father」那張卡片的 emoji 從 👨 改成 👨‍🦱。 【重要規則】 - 其他所有內容、設計、CSS、註解，完全保持原樣 - 不要重新排版、不要「順便優化」、不要替我精簡程式碼 - 請輸出完整的新 HTML，含所有未改動的部分， 讓我可以直接覆蓋原檔 以下是原始 HTML： （在這裡貼上你的整份 lesson1.html）

常見錯誤 vs. 正確做法

✗ 錯誤示範

「lesson1 的單字卡幫我改一下」

→ Gemini 會自由發揮，常常把你原本喜歡的設計也順手改掉。

✓ 正確做法

「只把第三張卡的英文從 brother 改成 grandfather，emoji 改成 👴，其他不動，輸出完整 HTML」

✗ 錯誤示範

只貼一小段 code 給 Gemini 看，希望它「補完」

→ 它會自己腦補你沒貼的部分，導致原始檔被簡化。

✓ 正確做法

把整份原始檔貼上去，明確指明修改範圍，要求「輸出完整新版本」

✗ 錯誤示範

沒備份就直接改，改壞了想還原找不回

✓ 正確做法

動手前先複製一份原檔，命名 _backup。確認新版沒問題才取代

給研習老師的提醒 維修最常見的災難是「想改一點點，結果整頁被 AI 重做」。把「只改 X、其他不動、輸出完整版」這三件事寫進每一次 prompt，就能避免 95% 的事故。

4. 上傳到 GitHub，把網站變公開

檔案做好了，但放在自己電腦裡只有你看得到。GitHub 是一個免費的「雲端硬碟 + 自動架站服務」：當你的資料夾裡有 index.html，它會幫你變成一個全世界都能連的真正網站。

① 申請 GitHub 帳號（免費，3 分鐘）

  1. 到 github.com，點右上角綠色 Sign up
  2. 用個人 email（不要用學校信箱） 學校信箱常常擋第三方驗證信，麻煩。
  3. 選一個 username 全小寫、不要空格、要短。這會出現在你的網址裡：username.github.io。建議用真名或短代號，不要選「sarah-english-teacher-2026」這種長串。
  4. 設密碼 → 收驗證信 → 點連結 完成。

② 建立你的第一個 repo

repo（repository）就是 GitHub 對「資料夾」的稱呼。要架網站，先要有一個 repo 來放檔案。

  1. 登入後，點右上角「+」→ New repository
  2. 取 repo 名稱 全小寫、用連字號分隔。例如：my-classroom、english-portfolio、grade3-english。這個名字會直接出現在網址，取了不太能改。
  3. Visibility 選「Public」 免費 GitHub Pages 只支援 Public。放心：公開的只有你上傳的 HTML 內容，不會洩漏 email 或密碼。
  4. 勾「Add a README file」 建議勾，讓 repo 不要是空的。
  5. 按綠色「Create repository」 你現在有一個雲端資料夾了。

③ 上傳 index.html 到 repo

  1. 進入剛建好的 repo 頁面
  2. 點「Add file」→「Upload files」 就在檔案列表上方。
  3. 把 index.html 直接拖到網頁中央的虛線框裡 也可以點選後選檔案。如果有圖片資料夾，整個 images/ 也一起拖。
  4. 滾到下方，按綠色「Commit changes」 檔案就上去了。

④ 開啟 GitHub Pages（讓網站上線）

到這一步，檔案在雲端但網站還沒上線。GitHub Pages 是 GitHub 提供的免費架站功能，要手動打開。

  1. 在 repo 頁面，點上方「Settings」分頁 在分頁列的最右邊。
  2. 左側選單捲下去找「Pages」並點進去
  3. Source 選「Deploy from a branch」 Branch 選 main，資料夾選 / (root)。
  4. 按「Save」，等 1 分鐘
  5. 重新整理頁面，會看到綠色框出現你的網址 長這樣：https://username.github.io/my-classroom。這就是你的網站，全世界都連得到。

⑤ 分享你的網址

網址直接傳 LINE、班級電子報、學校群組、家長會 LINE 群就好。學生、家長、校長，任何人只要點開連結就能看到你的網站，不需要登入、不需要安裝任何東西。

網站要更新怎麼辦 回到同一個 repo，「Add file」→「Upload files」，把修好的 index.html 拖上去覆蓋舊版（GitHub 會自動辨識同名檔案）。網站約 1 分鐘自動更新。維修流程（第 3 段）寫好的口訣，配合這個動作就是完整工作流。

5. 進階：買網域 + 用 Gemini 教你設定 DNS

如果你想要 www.mrwang-english.com 這種網址，而不是 username.github.io/my-classroom，可以買一個自己的網域。一年大約 NT$300–400。網域是你的，每年續約就一直是你的。

這一段是選配——免費的 github.io 網址其實已經夠用很多年了，等你想升級再做這步。

① 在哪買網域

網域商年費說明
Cloudflare RegistrarUS$9–12最便宜、不搞推銷，推薦

② 在 GitHub 設定你的自訂網域

  1. 回到你的 repo → Settings → Pages
  2. 在「Custom domain」欄位填入你的網域 例如：www.mrwang-english.com
  3. 按 Save GitHub 這邊就交代完了，接下來換網域商那邊。

③ 在網域商後台加 DNS 紀錄

DNS 紀錄就是「告訴整個網路：這個網址要指向 GitHub 的伺服器」。登入你買網域的網域商後台，加以下五筆紀錄：

TypeHostValue
CNAMEwwwusername.github.io
A@185.199.108.153
A@185.199.109.153
A@185.199.110.153
A@185.199.111.153

把 username 換成你自己的 GitHub username。儲存後等 10 分鐘到 24 小時，網域就會生效。

④ 不會設？請 Gemini 一步步教你

每家網域商的後台介面都長不一樣（Cloudflare、Namecheap、GoDaddy 都不同）。最直接的辦法是問 Gemini，請它針對你買的那一家給你逐步指引。

我剛在 Cloudflare 買了網域：mrwang-english.com 我的網站架在 GitHub Pages：username.github.io/my-classroom （請把 username 換成你自己的 GitHub username） 請逐步教我： 在 Cloudflare 後台的哪個位置、按哪個按鈕、在哪個欄位填什麼， 來新增以下 DNS 紀錄： - 1 筆 CNAME 紀錄 Host: www Value: username.github.io - 4 筆 A 紀錄（指向 GitHub 的 IP） Host: @ Value: 185.199.108.153 / 109.153 / 110.153 / 111.153 請用繁體中文，給我具體的操作步驟（不要只給觀念說明）。 如果我看不懂某一步，我會再追問。
最後一步：HTTPS 鎖頭 DNS 生效後（約 1 小時到 1 天），回到 GitHub → Settings → Pages，會看到「Enforce HTTPS」可以勾。勾起來，你的網址前面就會有 🔒 鎖頭，看起來像正式網站，瀏覽器也不會出現「不安全」警告。
不要急著買網域 新手最常見的陷阱是「網站還沒做好就先衝去買網域」。建議：用免費的 github.io 跑 3–6 個月，確定你會持續用，再買網域。網域沒續約就會被別人搶走，不要花冤枉錢。

心法總結

  • 越具體越好。主題、區塊、顏色、字體都要寫清楚，不要讓 AI 猜。
  • 一次只做一件事。不要叫它一次寫整個網站，也不要一次改五個地方。
  • 每次都備份。HTML 檔很小，多備份不會吃掉硬碟。
  • 修改時永遠加上「其他不動，輸出完整版」。這一條口訣可以避掉大部分慘案。
  • 瀏覽器是最好的檢查工具。雙擊 .html 就會開，邊改邊看，比甚麼都重要。
  • AI 不是魔法，是工讀生。你是設計師，方向是你定的。
