1 Step One

Create your free GitHub account.

GitHub is essentially Google Drive for code — a free place to store files online. When the folder contains an index.html, GitHub can turn it into a live website for the whole world. The free plan is enough for everything in this guide.

  1. Go to github.com. Click the green Sign up button at the top right.
  2. Enter your email. Use a personal email you check often — not your school address. Many schools restrict third-party verification emails.
  3. Pick a username. Short, lowercase, no spaces. This becomes part of your URL: yourname.github.io. Pick something you'd be happy to give to a parent — it stays with you for life.
  4. Create a password. Save it in your browser or password manager — you'll need it for every upload.
  5. Verify your email. Open the verification email from GitHub and click the link. You're in.
Tip · Keep your username short. "sarah-thomas" beats "sarah-thomas-english-teacher-2026" — the latter shows up in your URL forever.
2 Step Two

Prompt Gemini to write your HTML.

Open gemini.google.com and sign in with your Google account. Then describe the website you want, in plain English. The clearer your prompt, the better the result.

A starter prompt to copy

Sample Prompt
Write a single-file index.html for an English teacher's portfolio. Sections: • Hero with my name "Sarah Thomas" and a one-line bio • About me (2–3 short paragraphs) • Classes I teach (a list of 4 classes with short descriptions) • Contact (my email: sarah@example.com) Style: modern, one accent color (teal), Google Font "Inter", mobile-friendly. No external dependencies. Put all CSS and JS inside the same HTML file.

Iterate until it looks right

Don't expect perfection on the first try. Read Gemini's reply, then ask for changes in plain English:

  • "Make the hero section bigger and add a photo placeholder."
  • "Change the accent color from teal to navy."
  • "Add a section for parent reviews with three testimonials."
  • "The mobile version looks cramped — increase the padding."
Tip · Always ask for a single-file HTML and say "no external dependencies." That way the whole site is one file you can upload anywhere.
3 Step Three

Save the code as index.html.

Copy Gemini's full HTML output (look for the copy icon at the top of the code block). Then save it as a plain text file named exactly index.html.

On a Mac (TextEdit)

  1. Open TextEdit. It's in your Applications folder.
  2. Format → Make Plain Text. This is critical — TextEdit defaults to rich text, which will break your HTML.
  3. Paste Gemini's code.
  4. File → Save As → name it index.html. If TextEdit asks "Use .txt or .html?", choose Use .html.

On Windows (Notepad)

  1. Open Notepad.
  2. Paste Gemini's code.
  3. File → Save As → index.html. In the "Save as type" dropdown, choose All Files (otherwise Notepad will save it as index.html.txt).
⚠ Common mistake · Your computer may add .txt to the filename automatically. The file must end in .html — not .html.txt. On a Mac, turn on Finder → Settings → Advanced → Show all filename extensions so you can see what your file is really called.
4 Step Four

Create a new GitHub repository.

A "repository" is just GitHub's word for a project folder. You need one to hold your index.html.

  1. Click the "+" icon at the top right of github.com. Choose New repository from the dropdown.
  2. Name your repository. Lowercase, no spaces. Use a hyphen for word breaks. Examples: my-classroom, sarah-portfolio, grade-3-english. This name becomes part of your site URL.
  3. Set it to Public. Required for free GitHub Pages hosting. Don't worry — only the contents of index.html are public, not your email address or password.
  4. Tick "Add a README file." Optional, but it keeps the repository from being empty before your upload.
  5. Click the green "Create repository" button. You now have an empty folder online, ready for your index.html.
What your URLs will look like
Repository: github.com/yourname/my-classroom
Live website: yourname.github.io/my-classroom
5 Step Five

Upload your file.

  1. Open your new repository on github.com.
  2. Click "Add file" → "Upload files". It's the button just above the file list.
  3. Drag your index.html into the dashed upload area. Or click to browse your files.
  4. Scroll down to the green "Commit changes" box. You don't need to change anything in this box.
  5. Click the green "Commit changes" button. You'll see your index.html appear in the file list.
6 Step Six

Turn on GitHub Pages.

This last step is what takes your file and turns it into a live website that anyone can visit.

  1. Inside your repository, click the "Settings" tab. It's near the right end of the tabs row.
  2. In the left sidebar, scroll down and click "Pages."
  3. Under "Source," choose "Deploy from a branch." Set the branch to main and the folder to / (root).
  4. Click "Save." Wait about one minute.
  5. Refresh the Pages settings page. You'll see a green box with your live URL: https://yourname.github.io/my-classroom. That's your website. Share it with students, parents, the principal.
Updating your site later · Whenever you want to change something, just upload a new index.html to the same repository (Add file → Upload files → overwrite the old one). The site updates in about a minute.
7 Optional

Connect your own domain.

Want www.teachersarah.com instead of the default GitHub URL? You can — for around $10 per year. The domain is yours as long as you keep renewing.

Tell GitHub about your domain

  1. In your repository, go to Settings → Pages.
  2. Enter your domain in the "Custom domain" field. e.g. www.teachersarah.com
  3. Save and wait. DNS propagation usually takes 10 minutes to 24 hours.
  4. Tick "Enforce HTTPS" once the option becomes available (after the certificate is issued). This gives your site the padlock icon in browsers.
! Common Errors

Troubleshooting.

"My site shows the README instead of my page."

Your repository needs a file named exactly index.html at the top level. If GitHub is showing your README, your HTML file is probably named index.html.txt or sitting in a subfolder. Re-upload with the correct name.

"I clicked Save in Pages but nothing happens."

Wait at least 1–2 minutes, then refresh the Settings → Pages page. The green URL banner usually appears within 60 seconds, but first-time deploys can take longer.

"My custom domain doesn't load yet."

DNS changes can take up to 24 hours to propagate globally. If it's been less than a day, wait. If it's been more than 24 hours, double-check that all four A records were saved correctly at your registrar.

"My site has no styling — it looks like plain text."

Gemini may have generated separate CSS in a different code block. Either ask Gemini to inline all CSS into the same HTML file, or copy the CSS into a <style> tag inside <head>.

"I made a change to my file but the site looks the same."

Browsers cache pages. Force-refresh: ⌘ + Shift + R on Mac, Ctrl + Shift + R on Windows. Or open the page in a private/incognito window.
